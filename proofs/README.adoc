= Mathematical Proofs for 1000Langs
:toc:
:toclevels: 3

This directory contains formal mathematical proofs and specifications for the
1000Langs corpus crawler. The Agda tree is verified with
https://github.com/hyperpolymath/echidna[Echidna] tooling conventions and is
type-checked in CI by
`.github/workflows/echidna-verify.yml` (port of the job formerly stranded in
`hyperpolymath/standards`; see issue #4).

== Verified Tree and Trust Layering

The corpus is split so that everything load-bearing checks under Agda's
`--safe` flag, and the irreducible trust base is quarantined and audited:

[source]
----
proofs/
├── theories/
│   ├── InformationTheory.agda            # public module: theorems (agda --safe)
│   ├── InformationTheory/
│   │   ├── Foundations.agda              # total, postulate-free definitions (agda --safe)
│   │   └── Axioms.agda                   # THE ONLY quarantine holding `postulate`
├── specs/                                # design sketches (NOT yet machine-checked)
│   ├── alignment.spec
│   ├── iso639.spec
│   └── statistics.spec
├── trust-base.json                       # machine-readable axiom manifest (enforced by CI)
├── POSTULATE-AUDIT.adoc                  # human-readable audit of every axiom
└── echidna.toml                          # multi-prover pipeline config
----

Rules enforced by CI (`scripts/audit-trust-base.sh`, one of the workflow steps):

* `postulate` may only appear in `InformationTheory/Axioms.agda`;
* every axiom carries an `ECHIDNA:trust <class> :: <name>` tag and must match
  `trust-base.json` exactly — adding, removing, renaming, or reclassifying an
  axiom without updating the manifest and this audit fails the build;
* every safe module must keep `{-# OPTIONS --safe ... #-}`;
* the corpus must be non-empty (a gate with nothing to check is no gate);
* separately from the local audit, the estate `Trusted-Base reduction policy`
  job (`standards/scripts/check-trusted-base.sh`) walks the comment block
  directly above each `postulate` keyword for an `AXIOM:`/`TRUSTED:` marker —
  keep those leading blocks (no blank line between marker and keyword) and
  mirror every entry in `docs/proof-debt.md`.

`--safe` is not decoration: since Agda 2.6.1 it rejects `postulate` outright,
which is why the trust base is a separate non-safe module rather than
where-clauses scattered through the theorems (the pre-2026 corpus did the
latter, and the relations declared that way were vacuously satisfiable —
see POSTULATE-AUDIT.adoc).

== What Is Proven vs. What Is Axiomatic

*Proven in `InformationTheory`* (from IEEE-754 `ffi-fact` axioms only):

* `entropy-nonneg` — H ≥ 0 for entries in [0, 1], via the guarded, NaN-safe
  entry term `plogp` (its non-negativity on [0,1] is the one `ffi-fact`
  consumed) and a `sumF` induction transporting through `lookup-map`.
* `js-symmetric` — JSD(P,Q) ≡ JSD(Q,P), from commutativity of float addition
  and the symmetric midpoint construction.
* Vector plumbing (`lookup-map`, `sumF-nonneg`, `zipWith-cong₂`,
  `zipWith-comm`) and definitional sanity lemmas.

`Axioms.agda` (class `conjecture`, kept open deliberately):

* `kl-nonneg` — Gibbs' inequality; proof over reals needs the log-sum
  inequality plus a rounding bridge.
* `js-bounded` — Lin (1991) bounds; same.

== Proof Obligations (specs/ — design sketches, not checked)

The `.spec` files under `specs/` are *specification sketches* written in
Agda-like pseudo-syntax (they use a `theorem` keyword that Agda does not
have). They are inputs to future proof work, not verified artifacts, and CI
does not type-check them. Their intended obligations:

== Running the Checks Locally

[source,bash]
----
# Install the toolchain (matches the apt pin used by CI):
sudo apt-get install -y agda agda-stdlib

# Type-check the corpus exactly like CI + run the trust-base audit:
just prove-check-all

# Individual steps:
just prove-agda     # agda --safe / --without-K over proofs/theories
just prove-audit    # trust-base.json ⇄ source manifest gate

# Echidna pipeline (requires the echidna tool; CI does not depend on it):
just prove          # echidna verify
just prove-gen      # generate proof obligations
----

== Adding New Proofs

1. Put total definitions in `InformationTheory/Foundations.agda` (or a new
   `*/Foundations`-style safe module).
2. If — and only if — a fact is genuinely unprovable in Agda over its
   primitives, add it to `InformationTheory/Axioms.agda` with an
   `ECHIDNA:trust ffi-fact :: <name>` (IEEE-754 true fact) or
   `ECHIDNA:trust conjecture :: <name>` tag, update `trust-base.json` and
   `POSTULATE-AUDIT.adoc` in the same PR, and add the file to
   `theories`/`safe_modules` lists as appropriate.
3. Register the module in `proofs/trust-base.json` (CI fails on any unlisted
   `.agda` file).
4. Run `just prove-check-all`.

== Integration with OpenCyc (planned, not present)

and a `verified/` directory of Coq proofs; those files never landed and the
