=== The honest nuance you must not lose

* "The proofs type-check" covers 3 Agda modules. Two of them are deliberately
  checked without `--safe` because they hold the 5 postulates. Two of those
  postulates (`kl-nonneg`, `js-bounded`) are classed *conjecture*, not proved
  facts. Results that depend on them are conditional.
* The Agda check needed two overrides from the `scripts/prove-agda.sh`
  defaults. Run as shipped, with the real `HOME`, it exits 1 with
  `mkdir: cannot create directory '~/.agda/libraries': File exists`. The script
  treats `~/.agda/libraries` as a directory, but Agda reads it as a file. With a
  scratch `HOME` but no `AGDA_STDLIB_DIR`, it refuses with "stdlib probe failed".
  The pass above is the third run, with the stdlib passed explicitly.
* The 200 `meta/flags/*.png` images carry a licence annotation but no copyright
  holder. That is deliberate: their original authorship is not established
  (see NOTICE), and no holder was invented.

=== Known-incomplete but honestly fenced

* Postulated lemmas are fenced by `scripts/audit-trust-base.sh`. A postulate
  outside `InformationTheory/Axioms.agda`, or a count that differs from
  `proofs/trust-base.json`, fails it.
* A module that declares `--safe` cannot carry a postulate: Agda rejects it at
  check time.
