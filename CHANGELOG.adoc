= Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

== [Unreleased]

=== Added
- Agda proof verification CI (`.github/workflows/echidna-verify.yml`,
  resolving issue #4): hard-failing `agda --safe` type-check over
  `proofs/theories`, fail-closed corpus assertion, and a trust-base audit
  gating `proofs/trust-base.json` against the quarantined axioms
- Trust-quarantine layering for the Agda corpus
  (`InformationTheory` = theorems, `Foundations` = safe definitions,
  `Axioms` = sole non-safe `postulate` module, each axiom tagged
  `ECHIDNA:trust`)
- Proven theorems `entropy-nonneg` and `js-symmetric` (POSTULATE-AUDIT
  Phase 2 items), plus `just prove-agda` / `just prove-audit` /
  `just prove-check-all` recipes and a mirror-grade check in `.gitlab-ci.yml`
- Complete rewrite from Python to ReScript for type safety
- RSR Gold compliance infrastructure
- Echidna integration for mathematical proofs
- OpenCyc integration for semantic grounding
- Nickel-based configuration system
- Podman containerization (replacing Docker)
- Comprehensive Justfile with 70+ recipes
- Nix flake for reproducible development
- Full test suite with Vitest
- AsciiDoc documentation

=== Changed
- `Distribution` now carries range and normalisation hypotheses with a
  computational float order `_≤ᶠ_` (fixes the vacuous where-clause relations
  identified in POSTULATE-AUDIT; refutable-as-stated versions removed)
- `proofs/README.adoc` now describes the tree that exists; removed phantom
  references (`set_theory.agda`, `language_types.agda`, `verified/*.v`,
  `opencyc_integration.agda`) and labelled `specs/*.spec` as unchecked
  design sketches
- `proofs/echidna.toml`: theory/spec lists rebased to real files;
  `[ci] fail_on_unverified = true`
- Migrated from Python to ReScript
- Replaced requirements.txt with package.json
- Switched from Apache 2.0 to MIT + Palimpsest dual license
- Documentation format from Markdown to AsciiDoc (except SECURITY.md)

=== Removed
- All Python code and dependencies
- Docker support (replaced with Podman)
- Legacy crawler implementations

== [0.0.1] - 2018-XX-XX

=== Added
- Initial Python implementation
- Support for bible.cloud, bible.com, pngscriptures.org
- ISO 639-3 language code support
- Basic corpus alignment functionality
- Apache 2.0 license
